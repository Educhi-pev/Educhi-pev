### Tecnologías y herramientas

- **Frontend:** React, TypeScript, JavaScript, Vite, Tailwind CSS, Three.js.
- **Desarrollo móvil:** React Native, Expo, Zustand, Kotlin.
- **Backend:** Node.js, Express 5, Laravel, Java, Spring Boot, API REST.
- **Tiempo real:** Socket.IO, WebSockets, eventos y sincronización de estados.
- **Bases de datos:** PostgreSQL, MySQL, Supabase, MySQL Workbench.
- **Modelado y reportería:** Data warehouse, esquema estrella, hechos, dimensiones, triggers y vistas.
- **Cloud y despliegue:** AWS, Google Cloud, Railway, Docker.
- **Automatización e IA:** n8n, WhatsApp API, agentes de IA, prompt engineering y guardrails.
- **Pagos e integraciones:** Culqi, tarjetas, Yape, Plin y webhooks idempotentes.
- **Mapas y geolocalización:** MapLibre, OSRM y Nominatim.
- **Seguridad:** JWT, refresh tokens rotativos, RBAC, rate limiting y cifrado de extremo a extremo.
- **Redes:** TCP/IP, VLAN, LAN/WAN, routers, switches, Wireshark y Packet Tracer.
- **Sistemas operativos:** macOS, Linux, Windows y administración de sistemas.
- **Herramientas:** Git, GitHub, Figma, Postman y Google Workspace.

### 📱 Mandaditos — Full Stack Developer

Aplicación móvil de delivery y mandados para Paita.

- Publicada en Google Play y actualmente disponible en prueba cerrada.
- Desarrollé las vistas para clientes, repartidores, comercios y administradores.
- Implementé mapas y rutas con MapLibre, OSRM y Nominatim.
- Construí una API REST con Node.js, Express 5, TypeScript y PostgreSQL sobre Supabase.
- Implementé autenticación JWT con refresh tokens rotativos, rate limiting y consultas parametrizadas.
- Añadí seguimiento en tiempo real mediante Socket.IO.
- Diseñé un sistema de ofertas entre repartidores y clientes utilizando transacciones y advisory locks.
- Implementé un chat cifrado de extremo a extremo con X25519 y XChaCha20-Poly1305.
- Integré pagos mediante Culqi, incluyendo tarjetas, Yape y Plin.
- Diseñé un data warehouse con esquema estrella para reportería administrativa.
